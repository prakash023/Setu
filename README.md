\# Setu (सेतु)

Setu (सेतु) is my personalized Android TV launcher project, based on the open-source CleanYourTV project by Gathin23.



Original project: https://github.com/Gathin23/cleanyourtv



My goal is to adapt the existing Android TV launcher to my own preferences and create a clean, modern, and personalized TV experience.



\## Project Origin



I started Setu using the existing CleanYourTV project as my foundation instead of building an entire launcher from scratch.



I followed the original project's approach and used its existing codebase, layouts, and resources as the starting point for my own customizations.



CleanYourTV is the original project. Setu is my own customized version, maintained in a separate repository.



\## What I Have Customized



\- Project identity: I created a separate project named Setu (सेतु).

\- Project configuration: I changed the Gradle root project name to Setu.

\- Launcher name: I updated the launcher display name and relevant string resources.

\- Installed applications: I customized the launcher to display apps according to the applications installed on my own chromecast, rather than using the app selection from the original project.

\- Personal customization: I am adapting the existing interface and resources to match my preferences and requirements.

\- Version control: I created a separate GitHub repository to manage my code and track my changes.
